# PHASE 6.8 증강 도감과 기능 검증

## 증강 도감

`/aw augments`는 본인 도감을 엽니다. 첫 페이지에는 고유 시너지 5종의 구성원별 보유 여부와 완성도, 6종 진화의 실제 원장값과 달성 여부, 누적의 공명 배율 및 생명의 잔향의 현재 보호막과 발동 수치가 표시됩니다. 비활성화된 조합과 미보유 진화도 구분합니다. 다음 두 페이지에는 76종의 이름·희귀도·주 역할·효과 수치·발동 조건과 보유 여부가 표시됩니다. 보유 증강을 먼저 보여주고, 보유 항목에는 해당 경기의 중첩과 진화 상태를 표시합니다. 경기 진행 중 도감을 열어두면 경기 시계에 맞춰 갱신합니다.

증강 선택 중인 참가자는 기존 `/aw augment`로 선택 화면을 사용합니다. 도감·정찰·사망 분석은 항목을 이동할 수 없으며 화살표를 왼쪽 클릭해 페이지를 이동합니다. 선택·교환 화면의 버튼은 소유자와 현재 세션에서만 동작합니다. 모든 플러그인 화면의 아이템 이동을 취소하며, Shift 클릭·숫자 키·더블 클릭·드롭·드래그, 하단 인벤토리 클릭은 화면에서 아이템을 꺼내거나 제어 버튼을 누를 수 없습니다.

## 전투 액션바

표시 우선순위는 **선택 또는 일시정지 → 생명의 잔향 보호막 → 보급 개봉 → 망원경 정찰 → 증강 발동 → 방향 추적**입니다. 상위 표시가 사라지면 아직 유효한 하위 표시가 나타납니다. 확정된 전투 효과, 추가 피해, 치명 피해 방지, 사용형 증강의 성공적 발동을 표시합니다. 같은 플레이어의 발동 알림은 최대 2초에 한 번 표시하며, 지나간 알림을 다시 재생하지 않습니다.

## 관리자 프리셋

`/aw admin test presets`는 프리셋을 나열합니다. 활성 상태인 전투 실험실에서 `/aw admin test preset <플레이어> <프리셋>`으로 적용합니다.

| 프리셋 | 조합 |
|---|---|
| `steel_king` | 강철의 왕 |
| `infinite_barrage` | 무한 포격 |
| `calamity_train` | 재앙의 기관차 |
| `hell_lord` | 지옥의 군주 |
| `thousand_swords` | 천 개의 검 |
| `life_echo` | 생명의 잔향의 치명 피해 방지 증강 3종 |

기존 실험실의 권한, 테스트 월드와 경기 상태 검사를 사용합니다. 프리셋의 모든 구성원이 활성·구현 상태인지 먼저 검사합니다. 이미 가진 증강은 그대로 두고 빠진 증강만 부여하며 기존 선택·재추첨을 소비하지 않습니다. 진행 중인 증강 교환을 먼저 마치십시오. 실험실 설정과 종료 후 복구는 기존 절차를 따릅니다. [전투 실험실 설정](phase67-combat-lab-ko.md)

## 검증 범위

Java 25 단독 회귀는 등록 76종, 진화 목표 키 6종, 시너지 설정 5종, 프리셋 6종의 연결을 검사합니다. JUnit은 실제 진화 카운터 경계와 HUD 우선순위·만료를 검사합니다. Paper 프로브는 실제 Bukkit 인벤토리에서 플러그인 화면 식별과 모든 클릭 유형의 제어 허용 여부를 검사합니다. 서버 콘솔은 도감의 플레이어 전용 경로, 프리셋 목록 및 대기 중 적용 거부를 확인합니다.

실제 Minecraft 클라이언트 플레이는 `REAL_CLIENT_VERIFIED = NOT_RUN`입니다. 초반 PvP 처치 보상, 증강 수치와 경기 규칙은 기존 설정을 사용합니다.
