# PHASE 7.3 공개 전투 연출

## 표시 정책

| 등급 | 표시 대상 | 데이터 |
| --- | --- | --- |
| PRIVATE | 발동자 | 증강 문양, 성장, 충전 상태, 쿨다운, 준비 과정 |
| COMBAT_PUBLIC | 같은 경기의 유효한 참가자 | 확인된 공격·방어, 공개된 위험 범위 및 투사체. 공유 모델은 공통 도형과 효과음만 사용한다. |
| TARGET_FEEDBACK | 영향을 받은 참가자 | 공격 위치를 가시성 정책상 전달할 수 없을 때 피격자 자신의 위치에 일반 반응만 표시한다. |

공개 Display는 최대 24블록에서 보인다. 수신자는 관전자가 아니어야 하며 월드, 참가 상태, Bukkit 가시성, 투명 상태, 블록 시야를 확인한다. Display를 유지하는 동안 시야가 막히면 해당 뷰어에게서 숨긴다. 이미 로드된 청크를 통해서만 시야를 확인한다. 자원팩이 없는 참가자와 LOW 설정에는 바닐라 파티클을 보낸다. 경고 링은 장식 파티클 옵션과 분리되며 보이는 표본만 전송한다.

확인된 타격의 시각 효과는 피해 관측이나 합성 공격의 확인 지점에서 발생한다. 지연 폭발의 예고는 예약이 성공한 경우에만 생성하고, 예약 도중 갱신하며 발동에서 제거한다. 공허 장판은 실제 피해 범위와 종료를 사용한다. 화살과 마법 미사일의 공개 흔적은 실제 위치를 표본으로 삼는다. 실험실의 연출 재생은 전투 판정과 독립적이다.

위험 예고 → 실제 타격 및 방어 → 액티브 효과 → 장식 순서로 공개 대기열을 처리한다. 같은 공격 원점·증강·대상·형태·블록의 중복은 합친다. 다른 증강의 개인 발동은 각각 제한한다. 한 효과의 모델은 여러 뷰어가 재사용하며 24개 상한에서는 개인 장식부터 배정 해제한다. 타격 예산이 소진되면 조건부 파티클로 대체한다. 사운드는 소재별 바닐라 음원과 기존의 라이선스 확인 음원을 사용한다. [라이선스](../THIRD_PARTY_NOTICES.md)

## 조작과 품질

`/aw skill input hotbar|cycle|menu` 또는 `/aw ui`의 스킬 전환 입력에서 선택한다.

- `hotbar`는 웅크린 채 1~3번의 실제 핫바 슬롯으로 이동할 때 스킬을 함께 선택한다. 같은 번호를 다시 누르면 슬롯 변경 이벤트가 없으므로 아무 변화도 없다. 휠로 빈 스킬 슬롯을 지나가도 아이템 이동은 유지된다.
- `cycle`은 웅크리고 F를 누르면 빈 슬롯을 건너뛰어 순환한다. 전환이 이루어진 경우에만 보조 손 교환을 막으며 손에 든 아이템은 유지한다. 발동은 `/aw skill use` 또는 스킬 메뉴에서 한다.
- `menu`는 전환을 메뉴 및 명령어로 처리한다. 기존 웅크리기 + F 발동은 사용할 수 있다.

스킬 전환은 등록·쿨다운을 바꾸지 않는다. 액션바에서 선택 슬롯과 실제 쿨다운을 읽을 수 있다. `/aw ui`에서 그래픽 품질, 사운드, 파티클을 설정한다.

## 실험 및 성능

격리된 실험 경기에서 `/aw admin test preview demo`를 사용한다. `compare`는 같은 위치에서 개인 검기와 공유 검기를 순차 재생한다. `simultaneous`, `lifetime`, `repeat`는 동시 재생, 경고와 만료, 반복을 확인한다. `metrics`는 해당 경기의 모델·변환·전송 호출, 대기열 폐기와 폴백 카운터를 표시한다.

경기장 스캔은 메인 스레드에서 완료된 비동기 청크 요청을 소비한다. 기본 검사 시간 예산은 1,500µs로, 청크 검사 사이에 예산을 확인한다. 개별 청크 검사와 Paper의 청크 로드 자체에서 초과가 발생할 수 있다. 기존 안전 검사의 표본과 기준은 유지한다.

Paper 프로브는 실제 Display, 블록 시야 및 합성 뷰어를 사용한다. OFF 및 네 그래픽 품질의 같은 서버 부하와 네 규모를 비교하고, 별도 네이티브 피해 검사에서는 7.1-B와 7.2와 7.3을 한 CI 호스트에서 고정 Paper 빌드, 시드 67026, 동일 예열과 표본 수로 실행한다. 합성 부하의 전송 호출 수는 실제 네트워크 바이트를 나타내지 않는다. [검사 진입점](../scripts/compare-paper-versions.sh)
