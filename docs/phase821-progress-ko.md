## PART 1 · PREMIUM INTERFACE

### 디자인과 제작

경기 관제는 각진 금속 문장, 기록관은 펼친 책, 전투는 교차 칼날, 설정은 조정기, 관리는 황동 계측기로 구분한다. 화면 사이의 여백과 크게 구별되는 슬롯 모양을 이용한다. 기본 인벤토리와 기본 한글 글꼴, 제한된 아이템 모형을 사용한다. 상태는 명칭·소재·제어 가능 여부에 함께 반영한다. 장식은 빈 슬롯에 들어가며 처리 동작이 없다. 확인 버튼과 이동은 원래 Paper 이벤트·검증 경로를 사용한다.

세 희귀도에는 리벳이 있는 은제 섀시, 금제 방패와 양옆 장갑, 외부 수정과 궤도를 가진 다면체 구조를 사용한다. 84종 도감용 텍스처를 모두 새 소재로 제작했다. 16종의 중심 실루엣을 새로 그리고 68종은 기존 출처의 심볼을 가공했다. 128px 편집 원본은 생성기에서 재현할 수 있고 배포용 `folio/` 아이템 텍스처는 32px다. 전투 연출 모형과 기존 스킬 HUD가 사용하는 아이콘은 기존 파일을 참조한다. ## PART 2 · HUD & CONTROL REVOLUTION

기준은 `4405a64a34220f88d2e49a459397bc9c273d141d`다. PART 1의 도감·메뉴 모델과 텍스처를 유지하고 HUD 글꼴은 해당 도감 아이콘을 읽는다.

- **지속 정보**는 스킬 3슬롯 보스바와 기존 경기 사이드바에 있다. 선택 테두리와 준비·쿨다운·활성·빈 슬롯·잠금·취소 기호를 제공한다. 7종 액티브는 공통 충전 규칙이 없어 가짜 충전율을 표시하지 않는다. 실제 충전 반응형 증강의 기존 자동 상태 채널은 유지한다.
- **순간 알림**은 유한 큐에 표시한다. 같은 증강 ID는 병합하고 다른 증강과 피해·회복은 유효 시간 안에서 순차 표시한다. 치명 피해, 경계 밖, 부활·선택, 확인된 지연 폭발 대상 경고와 목숨 제한·서든데스 전환은 우선 표시한다. `AW_HUD_MATCH` 로그는 전송, 보스바 갱신, 스킬 조회, 입력 중복, 만료와 예산 초과 및 실제 누적 가시 시간을 기록한다.
- **조작**은 실제 발동의 공통 제한을 HUD와 확인음에 연결했다. 지면, 폭탄 비행, 시간 역행 기록은 조회 가능한 조건을 표시한다. 결투 대상·안전한 복귀와 돌진 위치는 입력 순간 판정한다. 실제 쿨다운 단위는 기존 경기 시계의 초다.
- **스킬 메뉴·안내**에 보유 스킬의 등록 칸·조건·쿨다운, 자동 등록 설정과 본인용 연출 미리보기를 넣었다. 첫 스킬 안내는 클릭 가능한 채팅에 남는다. `/aw guide`는 현재 설정에서 참가·시간·탐지·부활 규칙을 읽고 기존 격리 실험실로 안내한다.
- **자동 확인**은 큐 단위 검사, 기존 독립 회귀와 Paper 프로토콜 픽스처의 슬롯 전환·실제 발동·중복·쿨다운·부활 보호·빈 슬롯·일반 손 교환·재접속을 포함한다. Paper 부하 비교는 PART 1/2를 같은 Paper 257과 시드에서 실행한다. 측정 결과는 동일 커밋의 Actions 아티팩트에 기록한다.
- **미확인** 항목은 실제 그래픽 클라이언트와 GUI 배율 2·3·4, 실전 상태가 모두 겹치는 화면의 읽기 성능, PART 1에서 남긴 일부 증강별 세부 수치다. `REAL_CLIENT_VERIFIED=NOT_RUN`. 기존 1.75ms 목표의 통합 최적화는 PART 5 범위다.

## PART 3 · VISUAL EVOLUTION

기준은 `70ab670dd40e982bfb2eb8d02aca7654d1bc482f`다. 핵심 20종의 지오메트리와 표면을 교체하고, 우선순위 네 모델의 독립 트랙 여덟 개를 바꿨다. 84종 발동의 기존 호출 경로는 12계열의 표현과 고유 문양으로 이어진다. 기존 시그니처의 루트 시간표는 그대로 사용한다.

- 성장 연출은 실제 집계기와 설정 상한을 읽는다. 기존 25% 구간에서 모델에 장갑, 구동부, 검, 막 또는 룬이 추가된다. 영구 성장의 최대 단계와 여섯 진화의 완료 이벤트를 구분한다.
- 보급은 서버의 실제 개봉 진행도로 힌지를 움직인다. 정상적으로 처리된 개봉 보상과 연결해 모델을 닫거나 제거한다. 실제 상자·저장 원장은 그대로 사용한다. 각 뷰어의 시야와 청크 상태를 확인하고 공용 Display 예산 24개를 적용한다.
- Java 25 오프라인 Gradle과 JUnit, 독립 회귀, 배포 ZIP 재현 및 Blender 편집 원본을 검증했다. Paper 프로브, 강제 종료 복구, 동시 부하는 동일 SHA의 Actions 결과로 확인한다.
- 네 우선순위 외 코어는 기존 모션/시간표에 새 형상을 연결했다. 84종의 실제 발동 연결은 소스로 추적했고, 일반 발동 모션은 12계열을 공유한다. 개별 그래픽 클라이언트 전수 촬영, 거리별 실제 시인성, 실전 사운드 믹싱, 레퍼런스 대비 최종 시각 품질은 미검증이다. `REAL_CLIENT_VERIFIED=NOT_RUN`.
