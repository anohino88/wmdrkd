## PART 1 · PREMIUM INTERFACE

### 디자인과 제작

경기 관제는 각진 금속 문장, 기록관은 펼친 책, 전투는 교차 칼날, 설정은 조정기, 관리는 황동 계측기로 구분한다. 화면 사이의 여백과 크게 구별되는 슬롯 모양을 이용한다. 기본 인벤토리와 기본 한글 글꼴, 제한된 아이템 모형을 사용한다. 상태는 명칭·소재·제어 가능 여부에 함께 반영한다. 장식은 빈 슬롯에 들어가며 처리 동작이 없다. 확인 버튼과 이동은 원래 Paper 이벤트·검증 경로를 사용한다.

세 희귀도에는 리벳이 있는 은제 섀시, 금제 방패와 양옆 장갑, 외부 수정과 궤도를 가진 다면체 구조를 사용한다. 84종 도감용 텍스처를 모두 새 소재로 제작했다. 16종의 중심 실루엣을 새로 그리고 68종은 기존 출처의 심볼을 가공했다. 128px 편집 원본은 생성기에서 재현할 수 있고 배포용 `folio/` 아이템 텍스처는 32px다. 전투 연출 모형과 기존 스킬 HUD가 사용하는 아이콘은 기존 파일을 참조한다. [원본 생성기](../resource-pack/source/premium-interface.py) · [84종 전후 비교](art821/part1/icons-84.png) · [84종 감사표](art821/part1/icons-audit-ko.md)

### 빌드 및 서버 확인

Java 25 오프라인 Gradle 및 JUnit, 기존 독립 회귀, ZIP 재생성과 배포본 비교를 실행했다. 이 환경의 공식 Paper 빌드 목록 요청은 HTTP 403이었다. 실제 서버 검증은 같은 커밋의 GitHub Actions에서 확인한다. `InterfaceProbe`는 Paper 26.3에 접속한 프로토콜 클라이언트의 실제 인벤토리와 Paper 이벤트 경계로 메뉴를 검사한다. 화면·폰트 렌더링은 범위 밖이다.
