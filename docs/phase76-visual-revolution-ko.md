# PHASE 7.6 VISUAL REVOLUTION

## 무엇이 달라졌나

개별 액티브 조형은 회전 큐보이드와 면 텍스처로 내보낸다. Blender와 Paper는 같은 `art-signatures.tsv`의 위치, 회전, 비균일 크기 키프레임을 사용한다. 조형의 쿨다운과 효과 지속시간은 경기 데이터에서 결정된다.

| 능력 | 모델·모션 | 실제 발동 연결 |
| --- | --- | --- |
| 그림자 질주 | 이중 균열 검기, 출발점 수렴, 경로 잔상, 도착 스윕 | 성공한 순간이동의 출발·도착·실제 이동 벡터 |
| 지진술사 | 단층 파열, 독립 바위 조각, 지면을 따라 전개되는 균열 | 성공한 이동 방향과 실제 지연 타격 경로 |
| 시간 역행 | 이중 원형 시계의 역회전과 청록 수축 | 저장 위치로의 성공한 복귀 및 기록된 이동 경로 |
| 공허의 군주 | 중심 수정, 경계와 떠오르는 공허 파편, 종료 붕괴 | 장판 중심과 실제 위험 반경, 경기 시계에 따른 해제 |
| 폭탄 연금술 | 금속 프레임과 점화핵, 비행 회전, 충돌 후 팽창과 잔광 | 추적 투사체 좌표 및 충돌로 확정된 위험 반경 |
| 결투 계약 | 계약 링과 연결선, 청동 룬 각인 | 실제 상대 확정 후 두 참가자에게 개인 표시, 지속 중 시야 검사 |
| 재앙의 거인 | 입체 주먹이 하강하며 충격 파편으로 수축 | 실제 지면 피해 콜백의 중심과 반경 |

즉발 폭탄은 확정된 충돌 위치에서 폭발 범위를 표시한다. 지연 폭발은 기존 예약 시각과 실제 범위를 기준으로 사전 경고한다. 공개 전투 효과는 공용 모델과 소리를 쓰고, 실제 발동자의 고유 시그니처는 개인 발동과 미리보기에 사용한다. 결투의 개인 표시와 연결선은 유효한 상대 및 시야를 확인한다.

기존 진화 6종과 강철의 왕, 재앙열차, 무한 탄막, 지옥의 군주, 천검, 생명의 잔향 등의 전용 조형과 키프레임을 추가했다. 천검은 검 여러 자루를 하나의 모델에 넣었다. 확인된 일반·강한·치명타와 방어를 분리한다. 보호막 소모, 파괴, 회복은 실제 처리 결과에 연결된다. 13개 신규 효과음은 저장소 스크립트에서 합성했으며 기존 Kenney 음원의 라이선스는 그대로 적용된다.

84종 모두 아이콘과 모델 재질을 갱신했다. 일반 능력은 소재·역할별 유한 모션을 쓰며 주요 능력의 전용 사용과 나머지 공용 사용은 [84종 대조표](art71/augment-audit.md)에 기록했다.

## 인벤토리와 스킬 HUD

메인 메뉴의 참가, 상태, 추적, 팩 진단, 관리자 시작 등에 슬롯 전용 아이콘을 쓴다. 84종 카드에는 희귀도별 실루엣, 프레임과 명암을 적용했다. 도감 상세 카드에서 외형을 확인하고 활성 경기에서 소유자 전용 발동 미리보기를 재생할 수 있다. 프리즘 선택은 확정 이후 짧은 소리와 시각 효과를 표시한다. HUD는 세 슬롯의 번호와 상태를 압축하고 선택 스킬의 전체 이름과 세부 상태를 덧붙인다. 제목은 Minecraft 기본 인벤토리 글꼴과 레이아웃을 사용한다.

LOW는 짧은 기본 입자와 소리를 사용한다. STANDARD는 가까운 공용 3D 모델과 개인 중심 모델을 사용한다. HIGH와 ULTRA는 각각 추가 장식 레이어를 1개, 2개까지 사용할 수 있다. 동시 예산이나 점멸 감소 설정에 따라 장식이 줄어든다. 전체 Display 상한은 24개다. 위험 예고와 확인된 타격이 장식보다 우선하며, 자리가 부족하면 기본 입자와 소리를 사용한다.

## 설치

서버에 JAR을 설치한 뒤 새 팩과 동일한 SHA-1을 설정한다. URL과 해시는 설치 스크립트로 출력하거나 기존 설정에 적용할 수 있다.

```bash
python3 scripts/install-pack.py
python3 scripts/install-pack.py --apply /server/plugins/AugmentWild/config.yml
```

```yaml
art:
  url: "<스크립트가 출력한 공개 HTTPS ZIP 주소>"
  sha1: "dd850c8ad866b8f982ba60fb92e4e2388ca65a85"
```

기존 `config.yml`에는 값이 자동 복사되지 않는다. 업데이트하고 서버를 재시작한다. JAR에 기록한 해시와 서버 설정이 다르면 기본 화면을 사용한다. `/aw admin art validate`는 서버의 ZIP·SHA-1·에셋 참조를 확인한다. 플레이어는 `/aw art safe`로 개인 안전 모드를 전환할 수 있다.
