# 전투·사망 귀속

각 사건은 경기 UUID와 경기 내 일련번호, UTC 발생 시각과 경기 시각으로 구분한다. 공격자와 대상은 내부 참조에 쓰며 좌표와 실시간 상태는 보고서나 CSV에 공개하지 않는다. 기존 원본 공격 UUID는 관련 사건을 묶기 위한 키다. 일반·파생 타격은 각각 체력 변화가 확인된 경우에만 합계에 들어간다.

| 항목 | 실제 근거 | 귀속 경계 |
| --- | --- | --- |
| 원본과 최종 피해 | LOWEST의 기본 피해 표본, MONITOR의 최종 판정값 | 다른 플러그인이 후속 수정했거나 같은 값으로 귀속을 확정할 수 없으면 UNCLASSIFIED |
| 체력·흡수 | 다음 피해·회복·정기 정산 또는 실제 사망의 전후 관찰과 판정값 대조 | 취소 사건은 합계 0. 과잉·혼합 변화와 수치 불일치를 개별 증강으로 배분하지 않음 |
| 근접·원거리·치명 | 이벤트 원인과 치명타 표식 | 기본 타격에 덧붙은 증강의 별도 HP는 미분류 |
| 확정 파생·연쇄·액티브·지연 | 기존 합성 피해 컨텍스트의 증강 ID·원본 UUID | 근거 없이 일반 피해의 작성자를 추정하지 않음 |
| 갑옷·방패 | Paper이 제공한 별도 감산 항목 | 다른 증강과 중첩되어 확정할 수 없는 수치는 분리하지 않음. 방어량은 HP 손실에 더하지 않음 |
| 생명의 잔향 | 기존 소비 확인 원장이 승인한 보호막 차감 | 바닐라 흡수와 별도 저장 |
| 회복 | Bukkit 회복 이유와 최대 체력에 제한된 실제 증가량, 직접 회복의 전후 차이 | 효과가 섞인 회복·초과량은 집계에서 제외 |
| 치명 피해 방지 | 원래 능력이 성공을 확정한 위치의 구조화된 사건 | 실제 `PlayerDeathEvent`와 별개 |
| 사망 | 실제 사망 이벤트의 마지막 DamageType과 가해 엔티티, 경기 상태 머신의 최종 탈락 판정 | 환경 사망에 이전 타격자를 최종 피해자로 단정하지 않음 |

사망 GUI의 피해 그림은 확인 경로의 피해 원장을 읽는다. 별도의 유한 저널에서 회복·방어·발동·귀속 불일치 표본을 가져와 시간순으로 표시한다. 연속 공격으로 표본 용량이 소진되면 원래 저장 한도와 조회 유효기간을 적용한다.

통계의 제시·선택·재추첨은 실제 선택 회차에서 기록한다. 보유·진화 대상은 최초 획득, 진화 시점은 실제 진화 사건, 시너지·공명은 엔진 상태 전환, 성공·실패는 스킬 요청 처리, 파생 HP는 피해 정산, 회복·보호막은 각 원장의 확정 호출을 사용한다. 모든 증강의 일반 발동 합계가 완전하지는 않다. 패시브 효과 중 발동 횟수가 의미 없거나 기존 전용 카운터가 없는 유형은 운영 분석에서 별도로 해석한다.

보급 보상은 기존 아이템과 스택 동작이 같으므로 획득 이후 같은 아이템의 소비 출처는 `UNCLASSIFIED`다. 품목별 활용도는 운영 표본과 별도 식별 경계가 확보될 때까지 판정하지 않는다.
