# PART 2 · 알림 표시시간

GIF와 CSV는 50ms마다 실제 Java `HudMessages`를 구동한 결과다. 스킬 칸과 배경은 설명용 도식이다. Minecraft 그래픽 출력과 실제 프레임 계측은 미실행이다.

| 알림 | 계획 누적 가시 시간 | 최대 큐 수명 |
| --- | ---: | ---: |
| 피해·방어·회복 | 1.0초 | 3.2초 |
| 증강 발동 | 1.4초 | 6.5초 |
| 스킬 피드백 | 1.8초 | 3.5초 |
| 성장 | 2.0초 | 6.5초 |
| 진화·최초 시너지 | 3.0초 | 8.5초 |
| 중요 보급 | 2.7초 | 7.0초 |

샘플에서 강철심장은 두 발동을 한 알림으로 병합해 0.6초와 0.8초에 나눠 총 1.4초 보였다. 경계 경고는 0.8초 즉시 우선했다. 피격 1.0초, 스킬 실패 1.8초, 검풍 1.4초를 표시했다. 마법 미사일은 유효시간이 지나 0.4초 뒤 제거됐다. 큐는 6개로 제한하며 표시 중 메시지는 포화로 밀어내지 않는다. 모든 알림이 고부하에서 계획 시간을 채우는 것은 보장할 수 없다.

16개 큐에 1,000틱씩 입력한 로컬 합성 측정을 네 차례 실행했다. 첫 회 p95는 29.464µs, 마지막 p95는 4.207µs였고 마지막 회에 실행 스레드가 777,472바이트를 할당했다. 마지막 회에는 화면 전환 992건, 최대 큐 4개, 병합 976건, 만료 176건, 예산 초과 0건을 기록했다. 이 측정은 자바 큐와 문자열 합성을 포함한다. Paper 틱, 네트워크 전송, 그래픽 프레임은 별도다.
