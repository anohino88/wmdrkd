# 성장형 증강 원장

기본 YAML 값이다. 실제 경기에서는 운영자가 설정한 상한과 실제 누적량으로 표시 단계를 계산한다. 능력치 단위와 적용 방식은 증강별로 다르므로 원장 수치를 피해량이나 체력으로 단순 환산하지 않는다.

0~24%는 기본 형태이고 25%, 50%, 75%, 100%에 새 부품을 표시한다. 진화가 있는 능력의 완료 시점에는 전용 진화 모델이 재생된다. 상한이 유효하지 않으면 퍼센트 단계를 표시하지 않는다.

중첩 공룡에서 표시하는 공명 조형은 기존에 계산한 활성 구성원 수를 사용한다. 공명이나 소유 증강을 추가로 부여하지 않는다.
