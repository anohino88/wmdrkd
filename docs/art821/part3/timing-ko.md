# 시간표와 오프라인 가시 범위

각 샘플은 실루엣 알파의 반 이상인 픽셀을 센다. 2틱마다 촬영한 프레임 중 최대 투영 픽셀의 70% 이상인 표본이 차지하는 시간을 추산했다. 장애물, 파티클, 카메라 움직임과 클라이언트 FPS는 이 측정에 포함되지 않는다.
