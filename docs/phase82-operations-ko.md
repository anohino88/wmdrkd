## 운영 명령

- /aw admin dashboard는 서버, 경기, 참가 가능 인원, 운영 및 실험 월드 로드, 팩 상태, 통계 상태, 평균 틱과 연출 계측치를 표시한다. 월드보더 수치를 읽으며 배치 가능성은 기존 /aw admin arena check에서 실제 검사한다.
- /aw admin config check와 /aw admin config migrate --dry-run은 기존 config.yml을 읽고 변경 목록만 출력한다. /aw admin config backup은 원문을 별도 파일로 복제한다.
- /aw admin config migrate --apply는 설정 버전과 보관 기간을 추가하고 기존 원문·주석·알 수 없는 값을 보존한다. 백업을 먼저 쓰고 검증한 임시 파일을 원자적으로 교체한다. 운영자가 별도로 설정한 팩 URL이나 게임 수치를 바꾸지 않는다. 적용 후 재시작한다.
- 사망 조회 길이는 새 설정 파일에서 15초이며 기존 설정의 사용자 값은 보존한다. 경기 결과는 프로세스 내 최근 참가자 256명의 마지막 결과를 유지한다.
