# PHASE 8.1 · CINEMATIC PACING

기준 커밋은 70434e6995f55033220c6fa0ef1f8749ff54075d다. 8.0의 모델·텍스처와 전투 판정 데이터를 유지했다. 주요 트랙은 형성·초기 동작의 틱을 유지하고, 타격 이후의 유지·감쇠 구간을 새로 작성했다. 재앙의 거인은 2틱에 타격 자세에 도달한 뒤 9틱에 반동 자세를 거치고 30틱까지 큰 실루엣을 유지한다. 퇴장은 크기를 줄여 표현한다.

## 재생 정책

- 기본 재생 시간은 그림자 28, 지진 52, 시간 56, 공허 50, 폭탄 발동 30, 결투 48, 거인 56, 착탄 40틱이다. 실제 폭탄이 착탄하거나 제거되면 비행 및 발동 장식을 닫는다. 공허 장판이 종료되면 기존 경고를 취소하고 붕괴 트랙을 별도로 시작한다. 지진은 실제 타격에 도달하면 타격 위치에서 연출한다.
- 시너지 최초 활성화 64–74틱, 진화 52–64틱, 공명 42–44틱. 전투 중 반복 시너지는 짧은 일반 모션을 쓴다. 공개 타격 12틱, 강타·치명타 18틱, 방어 16틱, 검기 24틱, 폭발·구조 32틱, 시간 복귀·공허 28틱이다. 위험 예고, 짧은 투사체와 궤적의 길이는 이전 값이다.
- 최대 120틱의 유한 원본 트랙을 허용한다. 파트는 자체 회전과 크기를 적용하고 본체의 이동을 따른다. 주 트랙과 파트는 마지막 보간이 끝난 다음 제거한다. 공격과 충돌 소리는 기존 사건 시점에 출력한다.
- /aw ui에서는 FAST 1.25×, BALANCED 1×, CINEMATIC 0.75× 중 선택한다. 본인만 보는 시그니처의 첫 10틱을 고정하고 그 이후 구간을 조절한다. 공유 Display의 타격과 위험 예고에는 공통 타임라인을 적용한다.
- /aw admin test preview의 촬영 연출 탭에서 3·8·16·24블록과 반복을 유지한다. 스킬 시그니처는 정상, 0.75×, 0.5×, 8.0 원본을 선택한다. 반복은 모델 정리 후 20틱을 쉰다. SHOWCASE는 플레이어의 영구 설정에 저장되지 않는다.
- 같은 위치의 반복 공개 연출은 한 Display의 잔여 효과를 공유하고 새 타격 피드백은 파티클·사운드로 처리한다. Display 24개를 넘기지 않는다. 실험실 metrics는 예정·실제 재생 틱, 형태 유지 추산치, 조기 종료 사유와 예산 대체 건수를 제공한다.
