# PHASE 7.7 VISUAL REFORGE

- 초승달 검기는 짧은 파편 대신 맞물리는 날과 어두운 외곽으로 구성한다. 그림자 도약은 성공한 순간이동의 출발점에서 도착점까지 실제 수평 이동과 높이 차이를 재생한다.
- 지진의 연속 균열과 높이가 다른 암석을 실제 지연 타격 경로에 배치한다. 경계 입자는 기존 공격 경로 폭을 사용한다.
- 시간 역행은 원형 테두리, 눈금, 시곗바늘을 사용하고 고품질 표시의 보조층을 반대 방향으로 회전시킨다.
- 공허에는 연결된 궤도와 중심수정을, 폭탄에는 금속 외피와 점화부를 넣었다. 계약은 쌍문양과 기존 사적 연결을, 거인은 손등과 손가락 및 하강 키프레임을 개선했다.
- 공개 충격파와 방어 효과의 실루엣을 갱신했다. 강철의 왕에는 왕관, 재앙의 기관차에는 전방 추진 실루엣을 추가했다. 상세창 정보 아이콘과 HUD 쿨다운 표기를 정리했다.
- 큐 용량은 36건, 동시 Display 상한은 24개다. 생략은 위험 예고, 타격·방어, 액티브, 시너지, 장식으로 기록하며 중복은 별도 집계한다.
