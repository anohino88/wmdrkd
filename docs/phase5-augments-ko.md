# PHASE 5 증강

각 회차 시작 시 현재 XP 레벨을 저장합니다. 레벨을 0–50으로 제한해 실버 `80−1.46L`%, 골드 `18+0.5L`%, 프리즘 `2+0.96L`%로 각 슬롯을 추첨합니다. XP는 소모하지 않습니다. 최종 회차는 재추첨을 포함해 프리즘 3종입니다. 한 화면의 ID는 서로 다릅니다. 희귀도 내에서 미보유 ID를 우선하고, 풀 부족 시 보유 ID를 허용합니다. 중복 획득은 효과를 중첩하지 않습니다. 세 XP 효과를 함께 보유하면 가장 높은 배율 하나가 적용됩니다.

재추첨은 경기당 한 번이고 마감 시각과 레벨 스냅샷을 유지합니다. 4종뿐인 프리즘 풀에서도 적어도 하나의 선택지가 바뀝니다. 마감 시 미선택자의 유효 선택지 중 ID 순으로 첫 항목을 적용합니다. 재접속 전에는 마지막으로 관측한 레벨을 사용하고 기존 선택과 재추첨 기록을 유지합니다. 화면을 닫은 경우 `/aw augment`로 다시 엽니다.

| 희귀도 | 증강 | 기본 효과 |
|---|---|---|
| 실버 | 경험 축적 | 정상 획득 XP +50% |
| 실버 | 광부의 기세 | 광석 채굴 후 채굴 속도 +35%, 6초, 재사용 12초 |
| 실버 | 기동 훈련 | 생존 중 이동 속도 +8% |
| 실버 | 응급 회복 | 상대 피격 후 체력 35% 이하에서 초당 체력 1, 4초, 재사용 30초 |
| 골드 | 경험 가속 | 정상 획득 XP +100% |
| 골드 | 배후 공격 | 상대 뒤의 근접 공격에 기본 피해 +20% |
| 골드 | 낙하 강타 | 낙하 중 상대 근접 공격에 기본 피해 +25% |
| 골드 | 전투 적응 | 상대 근접 피격 후 방어력 +3, 5초, 재사용 12초 |
| 프리즘 | 경험 폭발 | 정상 획득 XP +200% |
| 프리즘 | 광전사의 심장 | 체력 35% 이하로 상대 근접 명중 시 이후 근접 피해에 기본 피해 +25%, 5초, 재사용 20초 |
| 프리즘 | 최후의 저항 | 상대의 기본 피해 6 이상 공격을 받아 피해 35% 감소, 재사용 25초 |
| 프리즘 | 연쇄 추격 | 상대 근접 명중 후 이동 속도 +20%, 4초, 재사용 12초 |

발동 수치와 시간은 `config.yml`의 `augments.effects`, 공통 조건은 `augments.conditions`에서 설정합니다. 지속 효과와 재사용 대기시간은 경기 시계를 사용하고, 선택 제한시간은 현실 시계를 사용합니다. 사망 시 일시 효과는 해제되고 소유와 쿨다운은 유지됩니다. 영구 이동 속도를 포함한 속성 버프는 저장되지 않는 키 기반 modifier로 적용합니다.

실제 클라이언트 검증에서는 테스트용 기존 월드를 사용하고, 두 플레이어에게 서로 다른 XP 레벨을 설정한 뒤 메뉴의 수치와 XP 비소모를 확인합니다. 각 회차에서 클릭, Shift 클릭, 숫자키, 드래그, 마감 자동 선택, 첫 재추첨 성공과 이후 거부를 확인합니다. 피해·XP·채굴·이동 효과는 적용 전후를 비교하고, 사망·재접속·탈퇴·종료 직후 효과와 기존 스냅샷을 점검합니다.

## PHASE 6 작업 목록

- 기존 핵심 30종과 추가 34종 명세의 ID 및 동작을 이번 초기 12종과 대조하고, 미구현 ID를 확정해 순서대로 효과와 발동 회귀 검사를 추가합니다.
- 진화 6종 `steel_heart`, `magic_missile`, `sword_wind`, `infernal_conductor`, `tank_engine`, `berserk_engine`의 조건, 강화와 한 번만 적용되는 상태 전환을 구현합니다.
- 시너지 5종 강철의 왕, 무한 포격, 재앙의 기관차, 지옥의 군주, 천 개의 검의 획득·해제를 소유 변경에 연결합니다.
