# PHASE 7.2 전투 조작과 연출

## 서버 설치

Paper 26.3과 Java 25를 준비한다. GitHub Actions에서 플러그인 JAR을 받아 서버의 `plugins/`에 설치한다. 리소스팩 ZIP은 서버 리소스팩 설정에서 별도로 제공하며 플레이어마다 수락 여부를 확인한다. [설치 및 ZIP 검증](phase71-resources-ko.md)

## 플레이어 조작

| 조작 | 동작 |
| --- | --- |
| 웅크리기 + F | 선택된 발동형 스킬 사용 |
| 웅크린 채 실제 핫바 1~3번 선택 | 등록된 스킬 슬롯 선택. 숫자키와 휠 모두 같은 핫바 이벤트를 사용하며 실제 아이템 선택도 적용된다. |
| `/aw skill menu` 또는 빠른 메뉴 → 증강 스킬 | 슬롯을 고른 뒤 보유 스킬을 눌러 지정하거나 교체 |
| `/aw skill bind <id>`, `/aw skill bind <1~3> <id>`, `/aw skill next` | 기존 명령으로 슬롯 조작 |
| `/aw ui` | 단축 선택, 빈 슬롯 자동 등록, 품질, 오라, 점멸, 파티클, 효과음, 피해 표시 설정 |

승인된 발동형 스킬은 빈 슬롯부터 채운다. 첫 스킬이 선택되고 슬롯이 가득 차면 채팅의 교체 버튼을 제공한다. 슬롯을 옮겨도 같은 스킬의 경기 시간 쿨다운은 이어진다. 세 슬롯은 스킬 HUD에 함께 표시된다. 리소스팩 수락 플레이어는 전용 글리프를 보고, 그 외 플레이어는 스킬명과 문자 게이지를 본다.

## 실험실

관리자 권한으로 설정된 전용 실험 월드의 경기에서 `/aw admin test preview [검색어]`를 연다. 하단의 동작 선택으로 연출만 재생, 지급, 회수, 보유 스킬 발동을 전환한다. 실험 메뉴에서 장비, 체력 복구, 흡수, 쿨다운, 장판 미리보기, 진화 진행도, 시너지, 테스트 표적을 다룬다. 다음 선택까지 시간 이동은 1인 실험의 파밍 단계에서 경기 시계를 통해 처리한다.

`/aw admin test dummy stationary|moving|high|shield|report|clear`는 1인 실험에서만 적용된다. 표적은 실험용 몹이며 체력·흡수의 관측 순손실과 첫 피격 이후 틱 기준 DPS를 보여 준다. 플레이어 대상 전용 발동 조건에는 별도 검증이 필요하다.

## 연출 수명과 품질

성공한 발동은 실제 위치에서 짧은 모델 동작으로 시작한다. 그림자 질주는 이동 경로, 시간 역행은 실제 저장 위치 표본, 폭탄은 투사체 이동과 적중 위치, 공허는 원래 장판의 맥동과 종료를 사용한다. 적용된 오라는 경기 시간에 따라 갱신하고, 제거·퇴장·정리 시 모델과 오라를 폐기한다. 모델 렌더가 실패하면 전투 판정은 기존 처리 경로를 사용한다.

| 품질 | 리소스팩 연출 | 기하 파티클 기본 예산 |
| --- | --- | ---: |
| LOW | 간소 파티클 네 개 | 8회/틱 |
| STANDARD | 중심 모델 | 16회/틱 |
| HIGH | 중심과 궤도 보조 모델 | 24회/틱 |
| ULTRA | 중심과 회전 보조 모델 두 개 | 32회/틱 |

위 예산은 새 기하 효과의 발송 호출만 집계한다. 원거리는 표본을 줄이고 부하가 오르면 장식 레이어와 발송을 먼저 줄인다. 경기의 기존 판정과 경계 경고는 별도 경로를 사용한다. 비공개 디스플레이는 효과·장판·보급을 합쳐 최대 24개다.
