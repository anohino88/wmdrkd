## 액티브와 성장 연출

- **그림자 도약**은 검기 양 끝과 중심 두께를 달리하고, 출발에서 실제 도착까지 높이와 거리를 보간한다. 잔상은 기존 이동 경로에 제한된다.
- **지진술사**는 균열형과 하중이 있는 돌기 형태를 강화했다. 타격 시점에 경로 앞쪽 다섯 지점과 교차 분기에 있는 가까운 지표면에 먼지를 찍는다. 읽는 범위는 로드된 청크와 경로 고도 주변으로 제한된다.
- **시간 역행**은 시계 바늘을 구별하고 역회전 후반의 속도를 높였다. 저장된 이동 표본과 성공한 복귀 시점을 연출에 사용한다.
- **공허 군주**는 바깥 고리와 수정의 실루엣을 분리했다. 기존 지속 모델이 시그니처 형상을 쓰며, 공개 경계 예고는 기존 규칙과 범위로 남는다.
- **폭탄 연금술**은 코어 노출부와 점화 장식을 추가했다. 지속 모델의 방향은 실제 투사체를 따르고, 폭발 모델은 실제 충돌 좌표에서 빠르게 팽창한다.
- **결투의 계약**은 두 문양의 내부 표지를 구별하고 대상의 문양을 반대 방향으로 회전시킨다. 계약 연결은 기존 시야 및 대상 유효성 검사를 거친다.
- **재앙의 거인**은 주먹 손목과 금속 장식을 보강하고 타격 콜백에 하강과 반동 연출을 묶었다. 준비를 위한 별도의 대기 시간을 전투 판정에 추가하지 않았다.

강철심장의 외곽 보호 구조, 지옥의 전도체의 연결선, 탱크 엔진의 전면 장갑과 발사구, 마법 미사일의 발사 홈, 폭주 기관의 동력 장식, 검풍의 겹친 궤적을 갱신했다. 지옥의 군주는 하부 링, 재앙의 기관차는 차륜과 전면부, 무한 포격은 평행 발사대를 보강했다. 강철의 왕과 천 개의 검은 전개 모션을 바꿨다. 생명의 잔향은 보호심의 전면부를, 누적의 공명은 금속층을 보강했다. 누적의 공명은 실제 보유 개수에 따라 수직 비율이 달라진다. 진화 완료 모델은 기존 진화 콜백에서, 시너지는 기존 활성화·적중 경로에서 재생한다. 새 연출은 기존 피해, 부활, 쿨다운, 범위 및 증강 판정을 변경하지 않는다.

## 격리 서버와 촬영

1. Java 25와 공식 Paper 26.3이 필요하다. `scripts/prepare-visual-test.sh /tmp/aw-visual build/libs/AugmentWild-0.1.0-SNAPSHOT.jar`는 체크섬으로 확인한 Paper 빌드 257, 플러그인, 검증된 리소스팩 설정을 로컬 전용 테스트 디렉터리에 놓는다. Minecraft EULA를 읽고 동의한 뒤 그 디렉터리에서 `java -jar paper.jar --nogui`로 실행한다.
2. 별도 시각 검증 월드를 서버의 기존 월드 관리 도구로 준비하고 `visual_lab`으로 로드한다. 필요하면 `dev.combat-lab.world`에 이미 로드한 월드의 이름을 지정한다. 관리자에게 `augmentwild.admin`과 `augmentwild.admin.test` 권한을 부여한다.
3. Minecraft 26.3으로 로그인한다. `/aw admin art status`로 팩 응답을 기록하고, `/aw admin test solo` 또는 2인 `/aw admin test start`로 격리 경기를 시작한다.
4. `/aw admin test preview`의 **촬영 연출** 탭을 연다. 망원경 버튼으로 3·8·16·24블록을 선택한다. 반복 버튼으로 1회 또는 3회를 선택하고 시야가 열린 곳을 조준한 채 테스트 항목을 고른다. `/aw ui`에서 LOW·STANDARD·HIGH·ULTRA를 바꿔 반복하고 기존 **stopfx**로 정리한다. STANDARD의 공개 모델은 17블록 밖에서 파티클 표현으로 바뀐다. 촬영 타임라인은 피해나 보상을 발생시키지 않는다.
5. 실제 전투는 실험실의 스킬 지급·발동 또는 2인 공격으로 시행한다. 스킬명·시점·GUI 배율·품질·배경·팩 상태·실제 피해·Display 정리 여부를 함께 적는다. 1·3인칭, 3·8·16·24블록, 낮·밤과 GUI Scale 2·3·4를 구분한다. 두 플레이어가 동시에 있는 경우 벽 뒤나 은신 중 정보가 노출되는지도 기록한다. `/aw art safe`를 켜고 메인 메뉴·선택·도감·HUD의 기본 표현을 확인한다.
