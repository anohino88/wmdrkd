# PHASE 4 이후 확정 규칙

경험치 레벨 적용 범위는 0–50이다. 각 증강 선택지의 희귀도를 독립 추첨한다. 프리즘은 `2 + 0.96 × 레벨`%, 골드는 `18 + 0.5 × 레벨`%, 실버는 `80 - 1.46 × 레벨`%다. 레벨 50 이상은 실버 7%, 골드 43%, 프리즘 50%로 고정한다. 경험치 증강은 즉시 전투력을 희생하고 미래에 높은 희귀도를 얻는 투자형으로 설계한다. 기존 인챈트의 경험치 소비는 유지한다.

보급은 플레이어 장비와 경험치에 무관하다. 첫 일반 보급은 6–10분, 두 번째 일반 보급은 14–20분, 고급 보급은 23–28분 중 무작위로 발생한다. 이벤트마다 상자 한 개를 배치하며 2분 전 예고, 1분 전 좌표를 공개한다. 위치와 내용은 매 경기 무작위이며 내용물 추첨은 최초 생성 시 한 번만 한다. 일반 보급은 전투용 장비와 소모품, 고급 보급은 희귀 장비와 특수 보상을 제공한다. 획득은 원자적으로 처리하고 중복을 방지한다.
