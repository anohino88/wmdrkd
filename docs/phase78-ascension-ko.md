# PHASE 7.8 VISUAL ASCENSION

액티브 7종의 런타임 모션을 조정했다. 지진술사는 갈라지는 지면 가지를, 재앙의 거인은 손가락과 손등의 강조면을 추가했다. 공개 폭발은 충돌 후 수평 반경을 넓히며 높이를 낮춘다. 이 변환은 실제 피해 범위를 나타내는 기존 경계 표시와 별개다.

| 진화 | 시각적 중심 |
| --- | --- |
| 강철심장 | 두 엽과 하부 심핵 |
| 마법 미사일 | 단일 투사체와 발사 궤도 |
| 폭주 기관 | 톱니와 가열된 심부 |
| 지옥의 전도체 | 삼각 도체와 중심 장치 |
| 탱크 엔진 | 궤도·포탑·포신 |
| 검풍 | 한 자루 검과 이어지는 바람 날 |

강철의 왕은 왕관과 갑옷, 재앙의 기관차는 차체와 차륜, 무한 포격은 세 발사체, 지옥의 군주는 삼지 실루엣, 천 개의 검은 검열과 받침을 사용한다. 생명의 잔향은 보호 중인 심장, 누적의 공명은 쌓이는 금속층으로 표현한다. 84종의 기존 심볼은 개별 마스크에 맞춰 명암을 갱신했다.

메인 메뉴는 경기와 증강 기능을 나누고 조작 버튼을 재배치한다. 선택창은 후보 슬롯을 중앙에 배치하고, 도감의 목록 페이지는 좌우에 여백을 둔다. HUD는 일시정지·보호·경기 불가 상태에 잠금 표기를 사용한다. 인벤토리 제목은 기본 글꼴을 사용한다. 공개 연출은 틱 내 동일 좌표의 시야 결과를 재사용하며 전체 Display 한도는 24개다.

## 화면 검증 절차

1. Java 25 및 Paper 26.3 서버의 JAR을 교체한다. `python3 scripts/install-pack.py`가 출력하는 주소와 SHA-1을 `config.yml`에 입력하고 재시작한다.
2. Minecraft 26.3으로 접속해 팩 적용 상태를 확인한다. GUI 배율 2·3·4에서 메인 메뉴, 증강 선택, 도감 목록, HUD 및 안전 모드를 기록한다.
3. 격리 실험 월드에서 스킬별 영상의 발동·적중·종료를 기록한다. 1인칭과 3인칭, 3·8·16·24블록, 주간·야간을 나눠 캡처한다. 계약과 공개 가시성은 참가자 두 명 이상으로 확인한다.
